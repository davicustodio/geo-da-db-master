# ai-data-pilot-manager

Subprojeto dedicado ao **Modulo 3 (Control Plane)** do `geo-ia-db-master`.

## Escopo deste subprojeto
- Gestao de usuarios e papeis do sistema (`admin`, `manager`, `user`)
- Gestao de projetos e conexoes PostgreSQL/PostGIS
- Curadoria de `ddl`, `dictionary` e `questions`
- Orquestracao de treinamento do Vanna via `api-geo-nlp`
- Ambiente de homologacao de perguntas/respostas
