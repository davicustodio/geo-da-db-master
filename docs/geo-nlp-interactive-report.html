Executive Overview

Module 1: Core Intelligence API

Key Technologies

  • Python 3.11+
  • Vanna AI 2.0 (Custom Class Inheritance)
  • Pydantic AI (Agent Orchestration)
  • FastAPI (Async Endpoints)
  • PostgreSQL (App DB) + PostGIS (Target DB)

Primary Roles

  • Ingest DDL and generate embeddings.
  • Contextualize user queries via history.
  • Generate and validate SQL safely.
  • Route Geospatial results (GeoJSON vs WMS).
Code Snippet Concept
class GeoVanna(VannaBase):
  def process_request(self, query):
    # 1. Context Agent
    q = ContextAgent.refine(query)
    # 2. RAG & SQL
    sql = self.generate_sql(q)
    # 3. Safety Check
    if not SafetyAgent.validate(sql):
       return "Error"
    # 4. Geo Execution
    return GeoRouter.route(sql)

Module 2: Immersive Interface

Key Technologies

  • React 18 (Vite) + TypeScript
  • CopilotKit (Frontend AI SDK)
  • Leaflet / React-Leaflet
  • Tailwind CSS + Shadcn/UI
  • Zustand (State Management)

Features

  • Chat-Over-Map layout.
  • Homologation Mode (`?test=true`) for debugging.
  • Action Triggers: `update_map_view`, `add_wms_layer`.
  • Real-time feedback loop (Thumbs Up/Down).
Action Definition Concept
useCopilotAction({
  name: "updateMapLayer",
  handler: async ({ type, url }) => {
    if (type === 'wms') {
       L.tileLayer.wms(url).addTo(map);
    }
  }
});
