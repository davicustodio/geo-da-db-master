GEO-NLP INTELLIGENCE

A modular infrastructure transforming Natural Language into Geospatial SQL using Vanna AI 2.0 & Pydantic AI.

Executive Summary

This platform implements a robust pipeline to convert user questions into precise SQL queries for PostgreSQL/PostGIS. It leverages a three-module architecture: a Core Intelligence API (Python/Vanna), an Immersive Frontend (React/CopilotKit), and a Management Dashboard. The system is designed to handle complex geospatial operations, context retention, and continuous self-improvement through feedback loops.

The Intelligent Pipeline (Module 1)

01. Context Agent

Pydantic AI reformulates the user query using chat history to create a standalone question.

02. RAG Retrieval

Vanna AI searches the Vector DB for similar SQL examples, DDL, and documentation.

03. Prompt Build

Constructs a system prompt injecting Postgres rules, spatial logic, and retrieved context.

04. LLM Generation

The Large Language Model generates the raw SQL query based on the enriched prompt.

05. Safety Agent

Validates syntax and blocks forbidden commands (DROP, DELETE, UPDATE) using Pydantic.

06. Cost Estimator

Runs `EXPLAIN` on Postgres to predict processing time. Aborts if too expensive.

07. Execution

Runs the sanitized SQL against the PostGIS database to fetch the dataframe.

08. Geo-Routing

Decides between returning lightweight GeoJSON or generating a WMS Layer URL.

Key Technologies & Features

Vanna AI 2.0

The core engine providing RAG capabilities, training APIs, and prompt management. Treated as a library within Python.

Pydantic AI

Orchestrates the agents. Ensures structured outputs and validates logic flow between phases.

CopilotKit

Powers the frontend AI. Manages chat state and triggers actions like `update_map_view`.

PostGIS + Geoserver

Handles spatial data. Geoserver provides WMS styling for heavy datasets (1000+ features).

Homologation Mode

Enabled via `?test=true`. Shows generated SQL and allows feedback to retrain the model immediately.

Auto-Learning

Approved answers are automatically fed back into Vanna's training loop to improve future accuracy.
